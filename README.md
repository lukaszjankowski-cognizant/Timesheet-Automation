# Project Repository

This repository is dedicated to a project focused on creating an automated tool for B2B users using Cypress.

# AAD Login Configuration

To enable AAD login, you need to create a file named ***config.env.js*** and add it to the project folder. The content of the file should look like this:

{
    
    "aad_username": "your_cognizant_email",
    
    "aad_password": "your_password",
    
    "aad_name": "your_cognizant_email"
}
